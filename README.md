# Digital Currency Ecosystem

A comprehensive digital currency system designed for virtual reality environments, web applications, and decentralized ecosystems.

## 🚀 Features

### Core Blockchain Technology
- **Secure Blockchain**: SHA-256 hashing with proof-of-work consensus
- **Digital Wallets**: Cryptographically secure wallet management
- **Transaction System**: Fast and reliable transaction processing
- **Mining Rewards**: Incentivized block mining

### Virtual Reality Integration
- **VR Currency API**: Seamless VR application integration
- **VR Marketplace**: Buy and sell virtual items with digital currency
- **VR Sessions**: Manage transactions in VR environments
- **Real-time Updates**: Instant balance and transaction updates

### Web Application Support
- **RESTful API**: Complete HTTP API for web apps
- **JavaScript SDK**: Easy-to-use development kit
- **CORS Enabled**: Cross-origin support for web integration
- **Live Statistics**: Real-time blockchain metrics

### Ecosystem Features
- **Smart Contracts**: Programmable transactions and automation
- **Governance System**: Community-driven decision making
- **Voting Mechanism**: Democratic proposals with weighted votes
- **Decentralized Marketplace**: P2P trading platform

## 📦 Installation

```bash
npm install
```

## 🎯 Quick Start

### Run the Demo
```bash
node index.js
```

### Start the Web API Server
```bash
npm run start-api
```

### Run Examples
```bash
# Basic usage
node examples/basic-usage.js

# VR integration
node examples/vr-integration.js

# Smart contracts
node examples/smart-contracts.js
```
